# 搭場與撤場實務

## 整體流程

1. **準備**：確定場佈圖 → 估算總用電量 → 確認器材無誤、電線無損壞（測線）。
2. **架設**：架鷹架／燈架 → 上燈 → 走線。
3. **接電**：所有器材架好、每顆燈的線都走好後才接電（見「接電安全與三用電表」）。
4. **連接前後級並調燈**：燈具接到後級自行配置的 Channel；Power Pack 用排線、Dimmer 用訊號線接上 Console；再依活動需要設計場景。
5. **整理場地**：整線、打保險。
6. **撤場**。

## 鷹架

一組鷹架包含 H 架、叉架（X 架）及跨板。

*（以下要點補充自資料夾內《搭場線材講稿》；主講義此處為課堂填空）*

- 腳下墊厚紙板，避免刮傷地板。
- H 架有分上下；X 架要扣好小卡榫。
- **最高架兩層**。
- 跨板放上後要矯正。
- 上下鷹架**從裡面爬**。

## 掛燈（C 型夾）

- C 夾可以夾在鷹架的粗桿或場館的燈桿上。
- **先上燈再上架**。
- 鎖的螺絲朝內；不可用鉗子鎖。
- 線朝下。
- 沒有 C 夾、背扣時，必須用鐵絲固定牢靠。

## 燈架

- 注意平衡。
- 新燈桿不能放在舊燈架上；舊燈桿可以升得比較高。
- 記得墊片；線朝下。
- 打保險；留線（供升降）、繞線。

## 安全與保險

- 燈具要做保險：鷹架或燈架上用鐵絲；與黑線公母頭連接處也要做保險（打平結，線接線也通用）。
- 主電源線的保險打在電箱上；主電源線要攤開走，不要堆成一堆。
- 隨身帶幾卷電工膠。

## 走線與貼線

- 控台定位後不動，物件位置可能變動 → **控台端不留線，物件端留線**。
- **任何懸空的線都叫做未完工的線。**
- 訊號線與電源線分開走；注意公母頭方向。
- 沿牆角、走直線：有邊靠邊，沒邊拉直角。
- 用電工膠封線，貼緊。

## 線材收法

*（補充自《搭場線材講稿》）*

- **正反收**：頭朝內，第一圈正。
- 膠帶繞數：主電源線 4 處；黑灰線／麥克風線 3 處；AC-BAR 頭尾。

## Q&A：燈光

### Q1：搭場前的準備工作有哪些？

確定場佈圖 → 估算總用電量 → 確認器材無誤以及電線均無損壞，再拿出去接燈。這些準備可以減少搭場時的狀況，增加效率。

### Q2：如何架好一顆燈？

考慮舞台與場地的大小、光源與舞台的距離，選用不同型號的燈互補，讓舞台看起來有重點。PAR 燈可以加色片加強場景效果，冷暖色系互相搭配（冷：藍、綠；暖：紅、橙、黃）。

### Q3：如何接電？

接電是最危險的步驟，在所有器材架好、線都走好、要開始調燈時才接。接電源箱前先把 Breaker 切到 OFF；拆卸時也一樣先切 OFF。基本概念：**先接地線，再接火線；先拆火線，再拆地線。**

### Q4：燈光架設步驟為何？

接電後，把燈具接到自行配置的 Channel。Power Pack 必須用排線接上 Console 才能使用（Dimmer 也要用訊號線接 Console）；再依活動需要設計畫面場景。

### Q5：如何才算完成搭場？

最困難也最重要的是最後的整理場地。不管過程多凌亂，最後都要把線整理好（沿牆角、走直線、用電工膠封線），燈具做好保險。安全是搭場中最重要的事。

### Q6：撤場的注意事項？

第一步先把電箱主電源關閉，再拆其他燈具。燒紅的燈絲非常脆弱，等燈具冷卻後再拆，卸燈時避免碰撞。最後把所有器材集中清點。

### 備註

1. 不論用哪種控制系統，設計燈光時最先考慮的是：場地的電源供應是否足以負荷所有燈具的總瓦數，以及後級每一 Channel 的最大用電量。沒弄清楚就亂接，會跳電或損壞燈具。
2. Breaker 上不一定有螺絲，要自備。
3. 電線或主電源線異常發熱時，立即停用並關電，排除後再繼續。
4. 燈具不受 Console 控制時，檢查排線兩端有沒有接好，再重新操作。

## Q&A：PA

### Q1：搭場前的準備工作有哪些？

一樣先確定場佈圖，也就是聲音訊號的輸入與輸出位置；最終目的是讓聽者聽得清楚、聽得輕鬆。訊號線的準備也很重要：需要哪些線、哪些接頭（RCA、Phone、Canon、裸線）、各幾條，還有測線。

### Q2：如何架好喇叭？

務必用喇叭螺絲把喇叭鎖緊在喇叭架上，防止滑落。擺放位置要注意與聽眾的距離、左右音量的平均，以及有無聲音死角。詳細步驟見音響系統的「系統架設」。

### Q3：回授產生時該如何處理？

回授是訊號輸出輸入無限循環放大。可以從 Mixer 調小輸出、改變麥克風位置，或用 EQ 調小回授的頻率。
