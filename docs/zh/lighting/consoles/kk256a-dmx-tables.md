## King Kong-256A（KK256A）數位式燈光控制器

金剛系列控制器專為電腦燈設計，也可以搭配其他數位燈具。最多同時控制 DMX512 的 **256 個通道**。面板由基本操作區、燈具／場景區、功能區和編程區組成，**沒有主 Fader**；特色是一個 LCD 屏幕和兩個方便操作電腦燈的數據輪盤。

### 基本操作

**燈具控制**：燈具指示燈恆亮時，按下要控制的單元鍵（可多選），用 Fader 改變通道值，數值會進入編程區。**燈具操作沒有 Flash 功能。**

**保存 Scene（單步場景）**

1. （先按清除，避免存到不需要的數據）推好想要的畫面。只有編輯過的數值會進入編程區。
2. 按「保存場景」→ 選 &lt;A&gt; 保存單步場景（指示燈閃爍）。
3. 按要儲存的場景頁（未使用的儲存格會閃爍）。
4. 按要儲存的儲存格單元鍵（指示燈熄滅）。

儲存單位有兩種：「以燈具」會存該燈所有屬性；「以通道」只存修改過的通道值（建議）。

**保存 Chase（跑馬／多步場景）**（最多 100 步）

1. 按「保存場景」→ 選 &lt;B&gt; 保存多步場景。
2. 按場景頁 → 按儲存格單元鍵（屏幕顯示儲存格編號與目前步數）。
3. 推好這一步的畫面（也可用複製／導入帶入已存的資料）。
4. 按「確定」儲存並進入下一步，重複（每步之間可先按清除）。
5. 存完所有步驟，按「保存場景」儲存並退出。

**運行 Scene 或 Chase**：選場景頁後，按儲存格單元鍵即為 Flash；推開對應 Fader 即運行，數值代表總調光。最多同時運行一頁 16 格。

**設定跑馬速度**：運行該跑馬 → A 輪盤調速度（預設 1.0 s，秒數越大越慢）→ B 輪盤調淡入淡出（預設 FF,FF 為最大）→ 按 &lt;A&gt; 進入設定 → 再按一次 &lt;A&gt; 保存。

**編輯／刪除跑馬步數**：保存場景 → &lt;B&gt; → 場景頁 → 儲存格 → 用上下鍵選步數 → 推好畫面後按「確定」，可選插入步／覆蓋步／併入步；或直接按「刪除」刪掉該步 → 按「保存場景」退出。

**刪除 Scene／Chase**：選場景頁，連按兩次該儲存格單元鍵。**刪除全部**：設置 → 下一頁 &lt;B&gt; 擦除數據 → &lt;B&gt; 清除所有重演數據 → 確定。
