# 燈光系統

燈光系統的基本架構：**電箱供電給後級，前級送訊號給後級，後級控制燈具亮暗。**

`電箱（電源） → 後級（Dimmer／Power Pack） → 燈具`，`前級（Console） → 訊號線 → 後級`

| 想查什麼 | 去哪一頁 |
| --- | --- |
| P = I × V、一個電箱能接幾顆燈、相位 | 電學基礎與用電計算 |
| 觸電、三用電表、測電箱、接電口訣 | 接電安全與三用電表 |
| 斷路器、主電源線、黑灰線、類比／數位系統圖 | 架設器材與系統示意 |
| Power Pack、DX-1220 Dimmer | 燈光後級 |
| Touchlight、C-1201/1202、C-24X、MX、DMX 控台 | 燈光前級（各機台一頁） |
| PAR、佛式燈、ZOOM、效果燈、LED PAR | 燈具介紹 |
| 燈泡、反射鏡、照度單位、燈具維修 | 照明光學 |
| 正面光／側光／逆光、色片、設計步驟 | 舞台燈光設計 |
| 搭場、走線、收線、撤場 Q&A | 搭場與撤場實務 |
