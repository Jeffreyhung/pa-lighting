# 舞台燈光設計

## 設計理念

架設舞台燈時，除了安全、演出內容及節目需求，更要考慮燈具本身的特性，來決定用什麼燈、擺在哪裡。以 PAR-64 為例，不同鏡面（N／P／R／S）有不同的角度與適用距離（見「燈具介紹」）。

## 燈光的四個特性

| 特性 | 說明 |
| --- | --- |
| 亮度（Intensity） | 從眼睛能分辨的最小亮度到不能承受的最大亮度，都能給演出不同的生命 |
| 顏色（Color） | 最能直接表達情緒 |
| 分配（Distribution） | 光的形式和方向；不同組合創造出的光與影有不同的視覺效果 |
| 運動（Movement） | 亮起與暗掉的時間，就是燈光的節奏 |

## 燈光的四個目的

1. **選擇性的可見度（Selective visibility）**：舞台上的亮度都是被選擇、被設計出來的。
2. **形式的呈現（Revelation of form）**：用光的形式和方向讓畫面可以表達、可以說明。
3. **視覺組合（Composition）**：讓整個舞台融合為一體，或分割成區塊。
4. **氣氛塑造（Mood）**：塑造符合演出內容的氣氛。

## 舞台光的分佈

| 光位 | 位置與功能 | 重點 |
| --- | --- | --- |
| **正面光（Front Light）** | 從舞台正前方照向舞台，打亮整個舞台 | 多用 PAR-64 N 或 P 型，從觀眾席後方直接投射；通常不加色片，或加淺色（調色溫）色紙。不足時舞台灰暗、錄影色彩不鮮麗。高度要比站在台上的人高：太高下巴有陰影，太低麥克風的影子會投在臉上，**45° 最佳** |
| **側面光（Side Light）** | 舞台左右兩側，補足正面光照不到的身體兩側，讓觀眾看到完整的立體影像 | 距離近，多用 PAR-64 R 型。要與正面光均和：不足則不立體，太強則兩側鮮亮而正面昏暗。強調肢體線條（如舞蹈）時常只用側面光 |
| **背景光（Scene Light）** | 投射到背景片。背景是觀眾視野的終點，讓注意力集中在演出者身上 | 要把平面的背景打成立體的：光線要**分色、分層**（中間層、側邊層、最外層、上層、下層）。例：中間鮮麗的黃、側邊土暗的橙、最外層深遠的藍 → 中間突出、旁邊深沉。也可供雷射、電腦燈、效果燈投射圖樣 |
| **逆光（Back Light）** | 舞台正後方朝觀眾方向投射。把演員與背景分離、增加立體感；也用來做光束造型 | 最能刺激觀眾，舞台燈光效果最大的展現都在這裡。著重層次分明、顏色協調、光束分布與特效震撼。調燈時：內部的燈往外打、外部的往內打、上面的往下打、地板的往上打。特效例：用純白光、高瓦數、色溫略高於 3200K 的燈做燈暴 |
| **效果燈（Effect Light）** | 製造多樣的圖案、光點 | 適用於舞會等熱鬧的節目 |
| **頂光（Wash Light）** | 舞台正上方往下打，又稱洗光 | 把整個舞台勻合，製造氣氛，是基本照明光源之一 |
| **追蹤燈（Follow Spot）** | 追隨主演者，加強正面光以示凸顯 | 色溫高（3200–5200K），錄影時畫面偏藍，要加降溫紙 |

### Key light、Fill light、地板燈

- **Key light（主光、髮燈）**：在舞台上方偏前，補足正面光與側面光照不到的頭頂；也可以表達環境狀況及時間等情境。
- **Fill light（輔光）**：通常在 Key light 的反方向，打亮主光造成的陰影；不會太強以免搶過主光，用色多為主光的對比色。
- **舞台地板燈**：把整個地板打亮，增加整體視覺效果；可用 LEKO 調成微散狀投射。

## 色片

色片是耐高溫的濾光紙。光線透過時，大部分波長被吸收，只允許特定波長通過，這個通過的波長就是我們看到的顏色 — 又稱**減光調色**。

不同色紙的透光率不同：透光率越低，穿透的光越少、越暗，需要的燈具也越多。

色片可分冷暖色系互相搭配：冷色 — 藍、綠；暖色 — 紅、橙、黃。

## 設計步驟

1. 了解燈具本身的特性
2. 了解演出內容及節目需求
3. 考慮安全因素及場地狀況
4. 選擇適合的燈具及顏色
5. 設計擺設位置及方法
6. 做燈光變化及進出點（Cue）設計表

架燈時要考慮舞台與場地的大小、光源與舞台的距離，選用不同型號的燈互補，讓舞台看起來有重點。一場精緻的燈光，是把導演的想像畫面與劇本的指示完整呈現給觀眾；多觀察大自然，多看、多問。
