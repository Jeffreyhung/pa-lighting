# 混音機

音源不只一個時，就要靠混音機（Mixer）把多種音源混合處理，再由主輸出送到後級的訊號處理器或擴大機。有的混音機還同時具備 EQ、效果器或擴大機功能。混音機是 PA 系統的大腦。

## 各機台速查

| 機台 | 廠牌 | 特色 |
| --- | --- | --- |
| BX-2442 | Behringer | 8 單聲道 + 4 立體聲道、4 組 AUX、4 個 Subgroup、內建效果器（在 AUX 3） |
| EMX 5000-12 | Yamaha | 內建擴大機、雙效果器、主輸出圖形 EQ |
| GL2200-432 | Allen & Heath | 大型控台：6 組 AUX、4 個 Group、4 段 EQ、內建 1 kHz／粉紅噪音 |
| LM12 | Samick | 3 組 AUX、Tape／Video／Phono 輸入 |
| MX122 | Studiomaster | 12 軌、2 總輸出，構造最單純 |
| VX-16 | STK | B-Mix 副混音、Monitor Send、可切換 AFL／PFL |
| RM-124 | Roland | 12 輸入、A／B 兩組總輸出 |
| Action 20-02 |  | 小型機台、2 組 AUX、內建 1 kHz 訊號 |

## 共通概念（每一台都會遇到）

| 名詞 | 意思 |
| --- | --- |
| MIC IN（Canon／XLR） | 麥克風輸入，低阻抗、平衡式 |
| LINE IN（Phone） | 線路音源輸入，阻抗較高 |
| INSERT | 同一個孔同時輸出與輸入，用來外接效果器／壓縮器，需要 Y 型 Insert 線 |
| TRIM／GAIN | 輸入訊號大小 |
| PAD | 衰減輸入，用於較大的訊號 |
| +48V／Phantom | 供電給電容式麥克風。部分機台注明接非電容式麥克風時不可開；開啟後不要再插拔 |
| Low Cut／HPF | 切掉低頻（75–100 Hz 以下）以去除雜訊 |
| EQ | 修飾該軌音質 |
| AUX（Send） | 輔助輸出，送去監聽或效果器。**Pre-fader** 不受推桿影響（適合監聽）；**Post-fader** 跟著推桿變化（適合效果） |
| AUX Return | 輔助輸入，效果器處理完的訊號從這裡回來 |
| PAN／BAL | 左右聲道比例 |
| MUTE／ON | 該軌靜音／開啟 |
| PFL／AFL／SOLO | 監聽：Pre-Fader Listen（推桿前）／After-Fader Listen（推桿後） |
| Subgroup／Group | 副輸出，把幾軌先合在一起再送去主輸出或獨立輸出 |
| CLIP／PEAK | 訊號過載指示燈 |

## 共通注意事項

- 插拔各軌的線之前先 MUTE，避免瞬間訊號傷機台。
- 開機及接線前把推桿拉到底。
- 要記得選訊號流向，只推 Fader 訊號出不去。
- 推聲音要逆推。
- 依順序開關機，尤其是擴大機；斷電時立即關掉電源，復電後再依順序開機。
- 電源電壓確定為 110V；機台放在穩固的地方。
