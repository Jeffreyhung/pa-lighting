# 音響系統（PA）

PA 是 Public Address 的簡稱：利用音響器材把聲音擴大傳輸，做一對多的通訊。基本要件是**音源、擴大機、喇叭**，再加上混音機與各式訊號處理器。

訊號鏈：`Source 訊源 → Mixing 混音 → Processing 訊號處理 → Amplifying 放大 → Speaker 喇叭`

| 想查什麼 | 去哪一頁 |
| --- | --- |
| PA 流程、開關機順序、接線邏輯 | PA 總說與系統邏輯 |
| 麥克風種類、指向性、無線麥 | 音源與麥克風 |
| 某一台混音機的旋鈕／插孔 | 混音機（各機台一頁） |
| 壓縮限制器、EQ、效果器、802C、分音器 | 訊號處理器 |
| 擴大機功率、喇叭規格 | 擴大機與喇叭 |
| 場佈規劃、控台位置、通道清單、架喇叭、走線 | 系統架設 |
| 沒聲音、回授、雜音、交叉查線 | 問題檢查與交叉查線 |
| 平衡／非平衡、接頭腳位、焊線、DI | 訊號線與接頭 |
