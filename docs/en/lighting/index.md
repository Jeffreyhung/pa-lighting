# Lighting System

The basic architecture: **the power box feeds the dimmer, the console sends a control signal to the dimmer, and the dimmer controls how bright the fixtures are.**

`Power box → Dimmer / Power Pack → Fixtures`, and `Console → signal cable → Dimmer`
