# Mixers

With more than one source you need a mixer to combine them and send the main output on to the processors or amplifier. Some mixers also include EQ, effects or an amplifier. The mixer is the brain of the PA system.

## Common concepts

| Term | Meaning |
| --- | --- |
| MIC IN (XLR, called "Canon" in the source) | Microphone input, low impedance, balanced |
| LINE IN (1/4" jack, called "Phone" in the source) | Line-level input, higher impedance |
| INSERT | One jack that sends and returns at once, for an external effect or compressor; needs a Y insert cable |
| TRIM / GAIN | Input level |
| PAD | Attenuates the input, for hot signals |
| +48V / Phantom | Powers condenser microphones. Some consoles warn not to use it with non-condenser mics; don't plug or unplug once it is on |
| Low Cut / HPF | Cuts lows (below 75–100 Hz) to remove noise |
| EQ | Shapes the channel's tone |
| AUX (Send) | Auxiliary output to monitors or effects. **Pre-fader** ignores the fader (good for monitors); **post-fader** follows it (good for effects) |
| AUX Return | Auxiliary input, where the processed effect comes back |
| PAN / BAL | Left/right balance |
| MUTE / ON | Channel mute / enable |
| PFL / AFL / SOLO | Monitoring: Pre-Fader Listen / After-Fader Listen |
| Subgroup / Group | Sub-output: combine several channels before the main mix or a separate output |
| CLIP / PEAK | Overload indicator |

## Common precautions

- Mute a channel before plugging or unplugging it, to avoid transients damaging the console.
- Pull faders fully down before powering on and before connecting.
- Remember to assign the signal; the fader alone sends nothing.
- Bring levels up in reverse.
- Follow the power sequence, especially for the amplifier; on a power cut switch off immediately and power up in order when power returns.
- Confirm mains voltage is 110V; put the console somewhere stable.
