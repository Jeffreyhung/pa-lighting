# PA System

PA stands for Public Address: using audio equipment to amplify and deliver sound from one source to many listeners. The essentials are a **source, an amplifier and speakers**, plus a mixer and signal processors.

Signal chain: `Source → Mixing → Processing → Amplifying → Speaker`
